# Plugins-
Plugins da Three Minds

| Plugin | Versão | O que faz |
|---|---|---|
| [`estudio-video-three-minds`](estudio-video-three-minds/) | 0.6.0 | Estúdio de vídeo: roteiro, novelinha vertical, editor de vídeo falado, edição automática (ffmpeg), Premiere/After Effects, Adobe, CapCut, geração com OpenAI e Runway e operação de canal |

## Instalar no Claude Code

```
/plugin marketplace add adorinirossi/Plugins-
/plugin install estudio-video-three-minds@three-minds
```

O repositório é privado: quem for instalar precisa ter acesso a ele no GitHub.
